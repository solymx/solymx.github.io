準備方式

圖片取自:O’Reilly
我先花約 4 小時把上完這本書讀完，就大概對雲端有個基本認識，大概可以腦袋有個概念他可能想考啥

之後想說上去 Google 官網看一下，了解 GCP ACE 考試相關資訊

他當時說 2025.06.30 要改版，改成以 AI, 自動化相關

因為我不想拖很久，怕說改版後會變不少，然後可能到時候市面上資源也要等一陣子才有，才能自學

所以就想趕快一個禮拜內讀完 + 考過

這邊簡單整理當時網頁寫的內容，如下

  • 考試 2 小時
  • 報名費用 125 美金 (實際上報名當下會打折，我報名費花約 2230)
  • 有效期限 3 年
  • 可以選擇在家考試 OR 恆逸教育訓練中心考試 (在家考還要弄環境麻煩，去恆逸比較好，免費的)

我之後跑去上 Udemy 的課程，就隨便選一個，然後用公司買的 Google GCP 平台跟著實作

本來想把在 Udemy 上面看的實作課程寫筆記，放到 github

只是做到一半，後面公司有點忙就沒在寫了，希望未來會補齊

考題內容概述

因為 2025/06/30 就會改版，我這是舊版 (考試時間 2025/06/12) ，可能很快就沒參考價值

考試主要是考兩個環境

  1. GCP GCE (VM)
  2. GCP Cluster (容器)

延伸就是

  • Cloud Function
  • Cloud Run

之後就是有關於

  1. IAM (權限控管)，要理解 Service Account
  2. 分配 Role (都要先加到 Group 再做後續分配)
  3. Pub/Sub

然後分支就是

  1. 如何省錢，控管預算
  2. 監控運作
  3. Log filter

網路通訊部分

  1. VPC 內部通訊
  2. 多個 VPC 通訊
  3. 地端和雲端通訊
  4. CIDR (基礎網管知識)

當時做的一點紀錄

  • 跟 timestamp 有關的是 Bigtable
  • SA 一開 VM 就要設定，不能事後改，Region 也是
  • Identity-Aware Proxy (IAP) 題目會扯到有關 Google 帳號
  • GCP 基本流程：先有 API -> 設置 Project -> 建置 instance
  • Admin Activity –> 記錄對資源的管理操作，建立修改刪除資源 or VM
  • 記錄對資料的讀取與寫入操作要看 Data Access audit logs (考試問你離職員工回來偷看公司資料)
  • 不同 Region 的 vm 通訊，僅需單一 VPC 即可
  • Pub/Sub → Dataflow → BigQuery：做即時資料分析
  • Pub/Sub → Cloud Functions / Run：做事件觸發的自動處理（如簡訊通知）
  • 身份聯邦 (Identity Federation): 中央化控管與簡化管理
  • Hyperdisk Extreme 是 GCP 最新一代超高效能區塊儲存，I/O 延遲、吞吐量都遠超 SSD
  • BigQuery 可以處理SQL 查詢、大資料分析
  • Cloud Functions 不支援直接部署 Docker image，要用 Cloud Run
  • 同一個 VPC 要通訊：Different region, different CIDR
  • BigQuery 主流計價模式有 2 種
    • On-demand pricing: 按查詢量（每 TB）計價，最常見預設模式
    • Capacity pricing: 按「計算資源（slot）用量」計費，可保留資源，適合高頻查詢 (舊名稱：Flat-rate pricing)
  • Pub/Sub 是設計來解決這種「生產者/消費者」架構的服務，能確保每條訊息（每筆訂單）至少被一個工作者（VM）處理一次，可以處理即時性服務
    • 題目情境常見：Order, Vote 這類活動
  • Vertical Pod Autoscaler (VPA) : 提供 CPU 與記憶體的建議（recommendations），可以幫你自動分析調整使用資源
  • App Engine 是 GCP 的完整 Serverless 應用平台，每次部署會自動保留舊版本（版本控制）

常見誤導

  • SA 是給程式，故意說給人，Cloud Identity 是給人，故意說給程式

參考的考古題

ExamTopics

  • 很多錯的
  • 一些網路販賣的考古題似乎都是爬蟲抄這些平台
  • 開始看這平台，發現不少錯的就不看了

PDFExamDumps

  • 超級垃圾，絕對不要買這平台的
  • 一開始隨便 Google 一份考古題，跳出這網站就刷下去，要 1600 台幣左右，題目錯超級多，越看越懷疑自己的知識，整份都讀完，超級爛
  • 嚴重懷疑他們是直接爬蟲撈網路平台資料，然後把網友投票最有可能是答案的選為答案，錯超多的垃圾地方

圖片取自:Udemy

  • 大推這一堂課程，我是 6/12 考的，可以看到上圖我購買時間是 6/10 ，大概花個兩天看她題目
  • 每一題都有詳細解釋 a, b, c, d 為啥正確或錯
  • 考試只有一題沒出現過，其他跟他平台上的完全一樣，選項是相同的，只是題目敘述不同
  • 私心覺得死背他題庫，啥都不懂也可以過就是了
  • 無業配

作者說還是會持續更新他的題庫，而且我當時買約花 760 台幣，比市面上便宜多了

蝦皮題庫賣 1000 ，我是沒買

海外題庫要 1000 以上，選這堂比較好

報名考試的方式

首先要上這個平台：https://cp.certmetrics.com/google/en/schedule/sso/kryterion

註冊和報名，如果不會可以參考這個 Youtube

姓名一定要跟護照的英文名字一樣，不然無法考試，重要!!

出意外

當時刷信用卡有過，但報名沒過，然後來回跟客服溝通 + 退費，他客服回應很快很不錯

然後有退費成功

考試當天

  • 至少 15 分鐘前到
  • 準備兩個證件 (要有英文名字, 要有大頭貼)，推薦：身分證, 信用卡, 駕照, 護照
  • 印出報名考試得到的信件，內有考試授權碼 (或你要用手機出示畫面似乎也可)

考完拿證照

我是去恆逸考試，電腦線上交券後，左上角會顯示 Pass 就是代表通過，不過不會知道自己成績

然後出來恆逸那邊也不會給你啥東西，不像考資安證照 CEH 那類會有成績啥的

之後就是等 Google 寄信到信箱

要記得去 Credly 註冊帳號，信箱要跟當初報名考 ACE 的相同

Google 會把證書丟到那給你，就能在網頁上看到自己的證照，也能下載
